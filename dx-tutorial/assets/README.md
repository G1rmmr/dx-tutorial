# 게임 모델

원본: `G1rmmr/dx-tutorial`의 `origin/feature/model`,
커밋 `c38f40b700d5eaf084be479b018f639dc1cad78f`.
`dx-tutorial/fbxs/*.fbx`의 바이너리를 그대로 보존했습니다.
동일 이름의 `FBX 2013` 호환본은 중복해서 가져오지 않았습니다.
기존 크레딧은 [SOURCE-CREDITS.txt](SOURCE-CREDITS.txt)에 보존했습니다.

`Game.cpp`에서 시작 시 한 번 임포트하여 기존 `Mesh` GPU 버퍼를 만듭니다.
원본 비율을 유지한 균일 배율을 적용합니다. 적은 모델 중앙을 원점으로 삼고
모델 경계에 맞춘 정적 Bullet 박스 충돌체를 사용합니다. 소품은 바닥 중앙이
원점이며 물리 충돌·획득·장착 동작은 없습니다.

임포터는 모든 메시 인스턴스를 순회하며 계층 및 기하 변환, Y-up 왼손 좌표계,
다각형 삼각분할, 반사 변환을 포함한 시계 방향 앞면을 처리합니다.
재질의 diffuse 색상과 정점 색상을 가져오고, 노멀 기반 고정 조명을 정점 색에
반영한 뒤 중복 정점을 합칩니다. 현재 `Vertex`의 위치·색상 형식을 유지합니다.

현재 범위는 작성된 정적 포즈입니다. 스킨 변형·애니메이션·UV 텍스처 샘플링은
지원하지 않습니다. FBX에 외부 텍스처 참조가 있어도 현재 색상 렌더링 경로에서는
재질 색상을 사용합니다. 원본 FBX는 보존되어 후속 기능에서 다시 임포트할 수 있습니다.

`ModelAsset.h`의 `ModelImportOptions`로 목표 크기, 높이/최장축 기준,
중앙/바닥 중앙 원점, 조명 반영 여부를 지정할 수 있습니다.
로드 실패는 파일 경로가 포함된 오류로 전달됩니다.

빌드 시 `assets` 전체가 실행 파일 옆으로 복사됩니다.
로더와 테스트 설명은 저장소 루트 [README](../../README.md)에 있습니다.
